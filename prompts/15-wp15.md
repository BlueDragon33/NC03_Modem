- Design tokens and shared components.

- Loading/error/offline/session-expiry/recovery states.
- Accessibility and human professional UX review.

## Non-goals
- No unrelated feature work.
- No endpoint/request/result inference without evidence.
- No PASS from CI alone when hardware/human evidence is required.

1. Audit all critical journeys and repeated components.
2. Refactor to one design system.
3. Compose desktop/tablet/mobile deliberately.
4. Run keyboard/touch/contrast/reduced-motion tests.
5. Run realistic user journeys.
6. Collect human review and remediate findings before PASS.

- [ ] Accessibility checks pass.

## Required evidence

- Work-package-specific artifacts and regression tests.
- Real-hardware or human evidence whenever this prompt requires it.
