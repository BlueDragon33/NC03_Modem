# NC03 Control Center

Website-app/PWA quản trị modem HYBRID Wi-Fi 5G NC03 theo kiến trúc local-first.

## Trạng thái
Foundation đang được triển khai theo nguyên tắc:

**Discover → Map → Implement → Test → Fix → Verify → Release**

Không hard-code API modem chưa xác minh, không lưu mật khẩu admin trên cloud, không sửa firmware NC03.

Repository này là source chính cho NC03 Control Center.
